# 实验二过程记录

## 运行环境

- Conda 环境：opencv
- 运行命令：`conda run -n opencv python experiment2.py`
- 主要库：OpenCV、NumPy

## 实验过程

1. 读取 `车牌.png`，灰度化并反色；先定位蓝色车牌区域，再在车牌 ROI 中进行阈值分割和字符轮廓筛选。
2. 读取 `器件测量.bmp`，按实验指导书要求截取左侧目标区域，阈值分割、反色含义下提取器件轮廓，用矩形框出零件并绘制两条宽度测量线。
3. 读取 `物件距离检测.png`，进行灰度变换、高斯去噪、Canny 边缘检测、膨胀和腐蚀处理。
4. 根据轮廓外接矩形获得参考目标和其他目标的坐标信息，取最左侧硬币为参考对象，设定参考宽度为 24.26 mm，计算像素比例和目标间距离。
