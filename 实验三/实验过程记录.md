# 实验三过程记录

## 运行环境

- Conda 环境：opencv
- 运行命令：`conda run -n opencv python experiment3.py`
- 主要库：OpenCV、NumPy

## 指导书读取情况

实验三指导书为旧版 `.doc` 文件，无法通过当前会话的 Word COM 直接打开；已从文件二进制文本中提取到实验要求。核心要求包括：图像预处理、边缘轮廓提取、圆孔和长形孔检测、孔心坐标、距离、长度、宽度和面积参数计算。

## 实验过程

1. 对 `image1.jpg`、`image2.jpg`、`image3.jpg` 进行颜色阈值分割，提取绿色工件区域。
2. 将工件外轮廓填充为实心区域，再在实心工件内部提取黑色孔洞，避免背景黑色区域干扰。
3. 对 `image1.jpg` 和 `image3.jpg` 的孔洞轮廓计算最小外接圆，得到圆心坐标、半径和面积，并计算孔心距离。
4. 对 `image2.jpg` 的黑色长形孔轮廓计算最小外接矩形，得到长、宽、面积和长形孔个数。
5. 将检测结果绘制在原图上，并保存参数摘要。
